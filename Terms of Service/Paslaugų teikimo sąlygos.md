### 4. Vartotojo elgesys ir API naudojimas
Programėlė veikia kaip kliento sąsaja ir tiesiogiai bendrauja su trečiųjų šalių API (**Chess.com** ir **Lichess.org**). Jūs įsipareigojate:
* Nenaudoti Programėlės šioms trečiųjų šalių paslaugoms priekabiauti, piktnaudžiauti, perkrauti ar siųsti nepageidaujamas žinutes (spam).
* Nebandyti atlikti atvirkštinės inžinerijos, dekompiliuoti, išardyti ar išgauti Programėlės pradinio kodo.
* Visiškai laikytis „Chess.com“ ir „Lichess.org“ paslaugų teikimo sąlygų bei API taisyklių, kai per Programėlę pasiekiate jų platformų duomenis.
* Neapeiti ir nebandyti apeiti užklausų limitų (rate limits), techninių saugumo priemonių ar apribojimų, kuriuos nustatė Programėlė arba trečiųjų šalių API teikėjai.
