ในการดาวน์โหลด ติดตั้ง หรือใช้งาน **ChessM8** ("แอปพลิเคชัน") คุณตกลงที่จะผูกพันตามข้อกำหนดในการให้บริการเหล่านี้ ("ข้อกำหนด") หากคุณไม่ยอมรับข้อกำหนดเหล่านี้ โปรดอย่าติดตั้งหรือใช้งานแอปพลิเคชัน

### 2. คุณสมบัติด้านอายุ
แอปพลิเคชันนี้ไม่ได้มีไว้สำหรับบุคคลที่มีอายุต่ำกว่า 13 ปี (หรือ 16 ปีภายในเขตเศรษฐกิจยุโรป) ในการใช้งานแอปพลิเคชัน คุณรับรองและรับประกันว่าคุณมีอายุขั้นต่ำตามที่กฎหมายในเขตอำนาจศาลของคุณกำหนดเพื่อทำสัญญาที่มีผลผูกพันทางกฎหมาย หรือได้รับความยินยอมจากบิดามารดา/ผู้ปกครองตามกฎหมายในกรณีที่ได้รับอนุญาต

### 3. การให้สิทธิ์การใช้งานและทรัพย์สินทางปัญญา
Tomasz Rutkowski ("ผู้พัฒนา") ขอมอบสิทธิ์การใช้งานส่วนบุคคล แบบไม่จำกัดแต่เพียงผู้เดียว ไม่สามารถโอนสิทธิ์ได้ และสามารถเพิกถอนได้ให้แก่คุณ เพื่อใช้งานแอปพลิเคชันสำหรับวัตถุประสงค์ส่วนบุคคลและไม่ใช่เชิงพาณิชย์บนอุปกรณ์เคลื่อนที่ของคุณ

* **ข้อห้าม:** ห้ามแจกจ่ายซ้ำในเชิงพาณิชย์ ให้สิทธิ์ช่วง หรือจำหน่ายแอปพลิเคชันหรือฟีเจอร์ที่รวมอยู่ภายในแอปโดยเด็ดขาด
* **การอนุญาตให้สร้างเนื้อหา:** คุณได้รับอนุญาตอย่างชัดแจ้งในการใช้แอปพลิเคชันเพื่อสร้างเนื้อหาวิดีโอทั้งในเชิงพาณิชย์และไม่ใช่เชิงพาณิชย์ (เช่น การสตรีมสดหรือการบันทึกการวิเคราะห์เกมหมากรุกบน YouTube, Twitch หรือแพลตฟอร์มที่คล้ายคลึงกัน)

### 4. ความประพฤติของผู้ใช้และการใช้งาน API
แอปพลิเคชันทำหน้าที่เป็นส่วนต่อประสานสำหรับผู้ใช้ (Client Interface) และโต้ตอบโดยตรงกับ API ของบุคคลที่สาม (**Chess.com** และ **Lichess.org**) คุณตกลงที่จะ:
* ไม่ใช้แอปพลิเคชันเพื่อคุกคาม ละเมิด ใช้งานเกินพิกัด หรือส่งสแปมไปยังบริการของบุคคลที่สามเหล่านี้
* ไม่พยายามทำวิศวกรรมย้อนกลับ (Reverse Engineer) ถอดรหัส แยกส่วน หรือดึงซอร์สโค้ดของแอปพลิเคชัน
* ปฏิบัติตามข้อกำหนดในการให้บริการและนโยบาย API ของ Chess.com และ Lichess.org อย่างครบถ้วนเมื่อเข้าถึงข้อมูลแพลตฟอร์มผ่านแอปพลิเคชัน
* ไม่หลีกเลี่ยงหรือพยายามข้ามขีดจำกัดอัตราการส่งคำขอ (Rate Limits) มาตรการรักษาความปลอดภัย หรือข้อจำกัดที่กำหนดโดยแอปพลิเคชันหรือผู้ให้บริการ API ภายนอก

### 5. ความพร้อมใช้งานของบริการและการหยุดชะงักของ API
แอปพลิเคชันต้องพึ่งพา API ของบุคคลที่สาม (Chess.com และ Lichess.org) ในการดึงข้อมูลเกมหมากรุกและข้อมูลผู้เล่น คุณรับทราบและตกลงว่า:
* หากผู้ให้บริการภายนอกเปลี่ยนแปลง API จำกัดการเข้าถึง ปรับเปลี่ยนรูปแบบข้อมูล หรือยุติการให้บริการ ฟังก์ชันบางส่วนหรือทั้งหมดของแอปพลิเคชันอาจไม่สามารถใช้งานได้
* ผู้พัฒนาไม่ต้องรับผิดชอบต่อการหยุดชะงัก การปรับเปลี่ยน หรือการสูญเสียฟีเจอร์ที่เกิดจากบุคคลที่สาม และไม่มีภาระผูกพันในการชดเชยหรือคืนเงินในกรณีดังกล่าว

### 6. การซื้อ การเรียกเก็บเงิน และการคืนเงิน
แอปพลิเคชันนี้ให้บริการในรูปแบบแอปพลิเคชันแบบชำระเงินผ่านร้านค้าบุคคลที่สาม (เช่น Google Play Store, Apple App Store)

* **การประมวลผลการชำระเงิน:** การชำระเงิน การเรียกเก็บเงิน และธุรกรรมทางการเงินทั้งหมดได้รับการจัดการอย่างปลอดภัยและครบถ้วนโดยผู้ให้บริการร้านค้านั้นๆ ผู้พัฒนาไม่ได้รวบรวม ประมวลผล หรือจัดเก็บข้อมูลบัตรเครดิตหรือข้อมูลการชำระเงินของคุณ
* **การคืนเงิน:** คำขอคืนเงิน การยกเลิก หรือข้อซักถามเกี่ยวกับการเรียกเก็บเงินจะต้องส่งไปยังฝ่ายสนับสนุนลูกค้าของร้านค้าที่ทำการสั่งซื้อโดยตรง และขึ้นอยู่กับนโยบายการคืนเงินของร้านค้านั้น ผู้พัฒนาไม่สามารถดำเนินการคืนเงินให้แก่คุณได้โดยตรง

### 7. ความเป็นส่วนตัว
ความเป็นส่วนตัวของคุณมีความสำคัญอย่างยิ่งสำหรับเรา การประมวลผลข้อมูลส่วนบุคคลหรือข้อมูลทางเทคนิคที่เกี่ยวข้องกับการใช้งานแอปพลิเคชันของคุณจะอยู่ภายใต้ **นโยบายความเป็นส่วนตัว (Privacy Policy)** ของเรา ซึ่งรวมอยู่ในข้อกำหนดเหล่านี้โดยการอ้างอิง

---

### 8. การปฏิเสธการรับประกัน
**ในขอบเขตสูงสุดที่กฎหมายที่ใช้บังคับอนุญาต แอปพลิเคชันนี้มีให้ "ตามสภาพที่เป็นอยู่" และ "ตามที่มีอยู่" พร้อมด้วยข้อบกพร่องทั้งหมดและไม่มีการรับประกันใดๆ ทั้งสิ้น**

ผู้พัฒนาขอปฏิเสธการรับประกันและเงื่อนไขทั้งหมดเกี่ยวกับแอปพลิเคชัน ไม่ว่าโดยชัดแจ้ง โดยนัย หรือตามกฎหมาย รวมถึงแต่ไม่จำกัดเพียงการรับประกันโดยนัยถึงความสามารถในเชิงพาณิชย์ คุณภาพที่น่าพึงพอใจ ความเหมาะสมสำหรับวัตถุประสงค์เฉพาะ และการไม่ละเมิดสิทธิ์ของบุคคลที่สาม

*ไม่มีข้อความใดในข้อกำหนดเหล่านี้ที่จะกระทบต่อสิทธิ์ตามกฎหมายที่คุณพึงได้รับเสมอในฐานะผู้บริโภคภายใต้กฎหมายท้องถิ่นที่เกี่ยวข้อง ซึ่งไม่สามารถสละสิทธิ์หรือจำกัดได้โดยสัญญา*

### 9. การจำกัดความรับผิด
ในขอบเขตที่กฎหมายไม่ห้ามไว้ ไม่ว่าในกรณีใด ผู้พัฒนาจะไม่รับผิดชอบต่อการบาดเจ็บส่วนบุคคล หรือความเสียหายโดยบังเอิญ ความเสียหายพิเศษ ความเสียหายทางอ้อม หรือความเสียหายสืบเนื่องใดๆ รวมถึงแต่ไม่จำกัดเพียงความเสียหายจากการสูญเสียผลกำไร ข้อมูลสูญหาย การหยุดชะงักทางธุรกิจ หรือความเสียหายหรือความสูญเสียทางการค้าอื่นๆ ที่เกิดขึ้นจากหรือเกี่ยวข้องกับการที่คุณใช้หรือไม่สามารถใช้งานแอปพลิเคชันได้

**ข้อสงวนสิทธิ์ด้านความปลอดภัยของอุปกรณ์:** คุณรับทราบว่าเนื่องจากแอปพลิเคชันจัดเก็บข้อมูลไว้ในอุปกรณ์ของคุณ คุณจึงมีหน้าที่รับผิดชอบแต่เพียงผู้เดียวในการรักษาความปลอดภัยทางกายภาพและทางระบบของอุปกรณ์ของคุณ ผู้พัฒนาจะไม่รับผิดชอบต่อการเข้าถึงข้อมูลในเครื่องโดยไม่ได้รับอนุญาต ความเสียหายของข้อมูล หรือความเสียหายของอุปกรณ์ที่เกิดจากมัลแวร์ การดัดแปลงระบบโดยไม่ได้รับอนุญาต ("Rooting" หรือ "Jailbreaking") หรือการดักจับข้อมูลบนการเชื่อมต่อสาธารณะที่ไม่ปลอดภัย

### 10. เนื้อหาของบุคคลที่สาม
แอปพลิเคชันแสดงเนื้อหา (เช่น เกมกระดานหมากรุกสาธารณะ ชื่อผู้ใช้ คะแนนเรตติ้ง) ที่ได้รับโดยตรงจากแหล่งข้อมูลภายนอก (Chess.com และ Lichess.org) ผู้พัฒนาไม่ได้ควบคุม รับรอง หรือรับผิดชอบต่อความถูกต้องหรือความพร้อมใช้งานของเนื้อหาบุคคลที่สามใดๆ

---

### 11. การชดใช้ค่าเสียหาย
คุณตกลงที่จะชดใช้ ปกป้อง และปกป้องผู้พัฒนาให้พ้นจากข้อเรียกร้อง ความรับผิด ความเสียหาย ความสูญเสีย และค่าใช้จ่ายใดๆ (รวมถึงค่าธรรมเนียมทางกฎหมายตามสมควร) ที่เกิดขึ้นจากหรือเกี่ยวข้องกับการใช้แอปพลิเคชันในทางที่ผิด การละเมิดข้อกำหนดเหล่านี้ หรือการละเมิดสิทธิ์ของบุคคลที่สาม (รวมถึงข้อกำหนด API ของ Chess.com หรือ Lichess.org)

### 12. กฎหมายที่ใช้บังคับและเขตอำนาจศาล
ข้อกำหนดเหล่านี้จะถูกควบคุมและตีความตาม **กฎหมายของประเทศโปแลนด์** โดยไม่คำนึงถึงหลักการขัดกันของกฎหมาย ข้อพิพาทหรือข้อเรียกร้องทางกฎหมายใดๆ ที่เกิดขึ้นจากหรือเกี่ยวข้องกับข้อกำหนดเหล่านี้จะอยู่ภายใต้เขตอำนาจศาลเฉพาะของศาลที่มีอำนาจในประเทศโปแลนด์

*หากคุณเป็นผู้บริโภคที่อาศัยอยู่ในสหภาพยุโรปหรือสหราชอาณาจักร คุณอาจได้รับประโยชน์จากบทบัญญัติบังคับของกฎหมายในประเทศที่คุณพำนักอยู่ด้วย*

### 13. การบอกเลิกสัญญา
ผู้พัฒนาขอสงวนสิทธิ์ในการยุติหรือระงับสิทธิ์การใช้งานแอปพลิเคชันของคุณทันทีโดยไม่ต้องแจ้งให้ทราบล่วงหน้า หากคุณละเมิดข้อกำหนดใดๆ ในสัญญานี้ เมื่อมีการบอกเลิกสัญญา คุณต้องหยุดใช้งานแอปพลิเคชันทั้งหมดและลบสำเนาทั้งหมดที่ติดตั้งบนอุปกรณ์ของคุณ

### 14. การอัปเดตและการเปลี่ยนแปลงข้อกำหนด
ผู้พัฒนาขอสงวนสิทธิ์ในการปรับเปลี่ยน ระงับ หรือยกเลิกฟีเจอร์ใดๆ ของแอปพลิเคชันได้ตลอดเวลา นอกจากนี้ เราอาจอัปเดตข้อกำหนดเหล่านี้เป็นระยะๆ การใช้งานแอปพลิเคชันต่อไปหลังจากการประกาศข้อกำหนดที่อัปเดตถือว่าคุณยอมรับการเปลี่ยนแปลงดังกล่าว

### 16. เงื่อนไขการคืนเงิน
ภาษาอย่างเป็นทางการของฝ่ายสนับสนุนลูกค้าคือภาษาอังกฤษ (สหรัฐอเมริกา) เราดำเนินการคืนเงินตั๋วในภาษาอื่น ๆ แต่จะได้รับการประมวลผลด้วยความช่วยเหลือของระบบการแปล AI เรารับรองว่าการแปลอัตโนมัติจะไม่ส่งผลเสียต่อการประเมินตั๋วคืนเงิน และจะได้รับลำดับความสำคัญเช่นเดียวกับตั๋วภาษาอังกฤษ
