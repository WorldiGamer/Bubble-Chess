---

### 1. การยอมรับข้อกำหนด
การดาวน์โหลด ติดตั้ง หรือใช้งาน **Chess M8** ("แอปพลิเคชัน") ถือว่าคุณตกลงที่จะผูกพันตามข้อกำหนดการให้บริการเหล่านี้ ("ข้อกำหนด") หากคุณไม่ตกลงตามข้อกำหนดเหล่านี้ โปรดอย่าติดตั้งหรือใช้งานแอปพลิเคชัน

### 2. คุณสมบัติทางด้านอายุ
แอปพลิเคชันนี้ไม่ได้มีวัตถุประสงค์เพื่อการใช้งานโดยบุคคลที่มีอายุต่ำกว่า 13 ปี (หรือต่ำกว่า 16 ปีภายในเขตเศรษฐกิจยุโรป) ในการใช้งานแอปพลิเคชัน คุณขอรับรองและรับประกันว่าคุณมีอายุขั้นต่ำตามที่กฎหมายที่ใช้บังคับในเขตอำนาจศาลของคุณกำหนดเพื่อทำสัญญาที่มีผลผูกพัน หรือได้รับการยินยอมจากบิดามารดา/ผู้ปกครองตามกฎหมายแล้วในกรณีที่ได้รับอนุญาต

### 3. การอนุญาตให้ใช้สิทธิ์และทรัพย์สินทางปัญญา
Tomasz Rutkowski ("ผู้พัฒนา") มอบสิทธิ์การใช้งานส่วนบุคคล แบบไม่เป็นสิทธิ์ขาดแต่เพียงผู้เดียว ไม่สามารถโอนแก่กันได้ และสามารถเพิกถอนได้ แก่คุณในการใช้งานแอปพลิเคชันเพื่อวัตถุประสงค์ส่วนตัวและไม่ใช่เพื่อการค้าบนอุปกรณ์เคลื่อนที่ของคุณ

* **ข้อห้าม:** ห้ามแจกจ่ายในเชิงพาณิชย์ ให้สิทธิ์ช่วง หรือขายแอปพลิเคชันหรือฟีเจอร์ที่รวมอยู่ในแอปพลิเคชันโดยเด็ดขาด
* **การอนุญาตให้สร้างเนื้อหา:** คุณได้รับอนุญาตโดยชัดแจ้งในการใช้แอปพลิเคชันเพื่อการสร้างเนื้อหาวิดีโอทั้งในเชิงพาณิชย์และไม่ใช่เชิงพาณิชย์ (เช่น การถ่ายทอดสดหรือการบันทึกวิดีโอวิเคราะห์เกมบน YouTube, Twitch หรือแพลตฟอร์มที่คล้ายกัน)

### 4. ความประพฤติของผู้ใช้และการใช้งาน API
แอปพลิเคชันนี้ทำหน้าที่เป็นอินเทอร์เฟซฝั่งไคลเอนต์และโต้ตอบโดยตรงกับ API ของบุคคลที่สาม (**Chess.com** และ **Lichess.org**) คุณตกลงที่จะ:
* ไม่ใช้แอปพลิเคชันเพื่อก่อกวน ละเมิด ส่งคำขอเกินขนาด หรือส่งสแปมไปยังบริการของบุคคลที่สามเหล่านี้
* ไม่พยายามทำวิศวกรรมย้อนกลับ (Reverse engineer) ถอดรหัส (Decompile) แยกส่วน (Disassemble) หรือดึงซอร์สโค้ดของแอปพลิเคชัน
* ปฏิบัติตามข้อกำหนดการให้บริการและนโยบาย API ของ Chess.com และ Lichess.org อย่างเคร่งครัดเมื่อเข้าถึงข้อมูลแพลตฟอร์มผ่านแอปพลิเคชันนี้
* ไม่หลีกเลี่ยงหรือพยายามหลีกเลี่ยงข้อจำกัดอัตราการส่งข้อมูล (Rate limits) มาตรการรักษาความปลอดภัย หรือข้อจำกัดใดๆ ที่กำหนดโดยแอปพลิเคชันหรือผู้ให้บริการ API บุคคลที่สาม

### 5. ความพร้อมในการให้บริการและการหยุดชะงักของ API
การทำงานของแอปพลิเคชันขึ้นอยู่กับ API ของบุคคลที่สาม (Chess.com และ Lichess.org) ในการดึงข้อมูลเกมหมากรุกและข้อมูลผู้เล่น คุณรับทราบและตกลงว่า:
* หากผู้ให้บริการบุคคลที่สามเปลี่ยนแปลง API จำกัดการเข้าถึง เปลี่ยนแปลงรูปแบบข้อมูล หรือยุติการดำเนินงาน ฟีเจอร์บางส่วนหรือทั้งหมดของแอปพลิเคชันอาจไม่สามารถใช้งานได้
* ผู้พัฒนาไม่ต้องรับผิดชอบต่อการหยุดชะงัก การเปลี่ยนแปลง หรือการสูญเสียฟีเจอร์อันเกิดจากบุคคลที่สามดังกล่าว และไม่มีภาระผูกพันในการชดเชยหรือคืนเงินในกรณีดังกล่าว

### 6. นโยบายความเป็นส่วนตัว
ความเป็นส่วนตัวของคุณมีความสำคัญต่อเรา การประมวลผลข้อมูลส่วนบุคคลหรือข้อมูลทางเทคนิคใดๆ ที่เกี่ยวกับการใช้งานแอปพลิเคชันของคุณจะถูกควบคุมโดย **นโยบายความเป็นส่วนตัว** ของเรา ซึ่งรวมอยู่ในข้อกำหนดเหล่านี้โดยการอ้างอิง

---

### 7. การปฏิเสธการรับประกัน
**ภายใต้ขอบเขตสูงสุดที่กฎหมายที่ใช้บังคับอนุญาต แอปพลิเคชันนี้ได้รับการจัดหาให้อื่นในลักษณะ "ตามที่เป็น" (AS IS) และ "ตามที่มีอยู่" (AS AVAILABLE) พร้อมข้อบกพร่องทั้งหมด และไม่มีการรับประกันใดๆ ทั้งสิ้น**

ผู้พัฒนาขอปฏิเสธการรับประกันและเงื่อนไขทั้งหมดเกี่ยวกับแอปพลิเคชัน ไม่ว่าจะโดยชัดแจ้ง โดยนัย หรือตามกฎหมาย รวมถึงแต่ไม่จำกัดเพียงการรับประกันโดยนัยถึงคุณค่าพาณิชย์ คุณภาพที่เป็นที่พึงพอใจ ความเหมาะสมสำหรับวัตถุประสงค์เฉพาะ และการไม่ละเมิดสิทธิ์ของบุคคลที่สาม

*ไม่มีข้อความใดในข้อกำหนดเหล่านี้ที่จะกระทบต่อสิทธิ์ตามกฎหมายที่คุณคุ้มครองในฐานะผู้บริโภคตามกฎหมายท้องถิ่นที่ใช้บังคับ ซึ่งไม่สามารถสละสิทธิ์หรือจำกัดได้โดยสัญญา*

### 8. ข้อจำกัดความรับผิดชอบ
ภายใต้ขอบเขตที่ไม่ถูกห้ามโดยกฎหมายที่ใช้บังคับ ผู้พัฒนาจะไม่รับผิดชอบต่อการบาดเจ็บทางร่างกาย หรือความเสียหายที่เกี่ยวเนื่อง ความเสียหายพิเศษ ความเสียหายโดยอ้อม หรือความเสียหายที่เป็นผลสืบเนื่องใดๆ รวมถึงแต่ไม่จำกัดเพียงความเสียหายจากการสูญเสียกำไร การสูญหายของข้อมูล การหยุดชะงักทางธุรกิจ หรือความเสียหายหรือความสูญเสียทางพาณิชย์อื่นใด อันเกิดจากหรือเกี่ยวข้องกับการใช้งานหรือไม่สามารถใช้งานแอปพลิเคชันของคุณ

**การปฏิเสธความรับผิดชอบด้านความปลอดภัยของอุปกรณ์:** คุณรับทราบว่าเนื่องจากแอปพลิเคชันจัดเก็บข้อมูลไว้ในอุปกรณ์ของคุณโดยตรง คุณจึงเป็นผู้รับผิดชอบแต่เพียงผู้เดียวในการรักษาความปลอดภัยทางกายภาพและระบบของอุปกรณ์ของคุณ ผู้พัฒนาจะไม่รับผิดชอบต่อการเข้าถึงข้อมูลท้องถิ่นของคุณโดยไม่ได้รับอนุญาต การสูญหายของข้อมูล หรือความเสียหายต่ออุปกรณ์อันเกิดจากมัลแวร์ การดัดแปลงระบบโดยไม่ได้รับอนุญาต ("Rooting" หรือ "Jailbreaking") หรือการดักจับข้อมูลบนเครือข่ายสาธารณะที่ไม่ปลอดภัย

### 9. เนื้อหาของบุคคลที่สาม
แอปพลิเคชันจะแสดงเนื้อหา (เช่น เกมหมากรุกสาธารณะ ชื่อผู้ใช้ คะแนนเรตติ้ง) ที่จัดหาให้โดยตรงจากแหล่งข้อมูลบุคคลที่สาม (Chess.com และ Lichess.org) ผู้พัฒนาไม่ได้ควบคุม รับรอง หรือรับผิดชอบต่อความถูกต้องหรือความพร้อมใช้งานของเนื้อหาของบุคคลที่สามใดๆ

---

### 10. การชดใช้ค่าเสียหาย
คุณตกลงที่จะปกป้อง ชดใช้ค่าเสียหาย และปกป้องผู้พัฒนาจากการเรียกร้อง ความรับผิด ความเสียหาย ความสูญเสีย และค่าใช้จ่ายใดๆ (รวมถึงค่าทนายความตามสมควร) ที่เกิดจากหรือเกี่ยวข้องกับการใช้แอปพลิเคชันในทางที่ผิดของคุณ การละเมิดข้อกำหนดเหล่านี้ หรือการละเมิดสิทธิ์ของบุคคลที่สาม (รวมถึงข้อกำหนด API ของ Chess.com หรือ Lichess.org)

### 11. กฎหมายที่ใช้บังคับและเขตอำนาจศาล
ข้อกำหนดเหล่านี้จะถูกควบคุมและตีความตาม **กฎหมายของประเทศโปแลนด์** โดยไม่คำนึงถึงหลักการขัดกันของกฎหมาย ข้อพิพาทหรือการเรียกร้องทางกฎหมายใดๆ ที่เกิดจากหรือเกี่ยวข้องกับข้อกำหนดเหล่านี้จะอยู่ภายใต้เขตอำนาจศาลแต่เพียงผู้เดียวของศาลที่มีเขตอำนาจในประเทศโปแลนด์

*หากคุณเป็นผู้บริโภคที่มีถิ่นที่อยู่ในสหภาพยุโรปหรือสหราชอาณาจักร คุณอาจได้รับประโยชน์จากบทบัญญัติคุ้มครองผู้บริโภคที่บังคับใช้ตามกฎหมายของประเทศที่คุณพำนักอยู่ด้วย*
