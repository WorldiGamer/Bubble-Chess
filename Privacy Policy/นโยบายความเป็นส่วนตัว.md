## 2. การเก็บรวบรวมและการประมวลผลข้อมูล (สถาปัตยกรรมแบบ Local-First)
แอปนี้ได้รับการออกแบบด้วยแนวทาง "Local-First" ซึ่งหมายความว่าเราให้ความสำคัญกับความเป็นส่วนตัวของคุณโดยการเก็บรักษาข้อมูลไว้ในอุปกรณ์ของคุณเอง

### A. ข้อมูลส่วนบุคคล
แอปจะดึงข้อมูลเกมหมากรุกสาธารณะ (ไฟล์ PGN) จากบริการของบุคคลที่สาม ซึ่งอาจประกอบด้วย:
* ชื่อผู้ใช้ (เช่น จาก Lichess.org หรือ Chess.com)
* ตาเดินหมากรุก ตราประทับเวลา (Timestamps) และคะแนนเรตติ้ง

เราไม่ได้จัดเก็บข้อมูลส่วนบุคคลไว้บนเซิร์ฟเวอร์ของเราเอง ข้อมูลจะถูกส่งตรงจากอุปกรณ์ของคุณไปยัง API ของบุคคลที่สามตามคำขอของคุณเท่านั้น

### B. ข้อมูลทางเทคนิค
* **ที่อยู่ IP (IP Address):** เมื่อแอปเชื่อมต่อกับ API ของบุคคลที่สาม ผู้ให้บริการเหล่านั้น (Chess.com/Lichess) จะเห็นที่อยู่ IP ของคุณ แต่ข้อมูลนี้จะไม่ถูกส่งมายังเราหรือจัดเก็บโดยเรา

### C. การขอสิทธิ์เข้าถึงของอุปกรณ์
เพื่อให้แอปทำงานได้ จำเป็นต้องมีสิทธิ์ดังต่อไปนี้:
* **การเข้าถึงอินเทอร์เน็ต:** เพื่อเชื่อมต่อกับ API ของ Chess.com และ Lichess.org โดยเฉพาะ
* **พื้นที่จัดเก็บข้อมูล (อ่าน/เขียน):** เพื่อบันทึกและเรียกดูไฟล์ PGN บนอุปกรณ์ของคุณ (ตามความเหมาะสม)

## 3. วัตถุประสงค์และฐานทางกฎหมายในการประมวลผล

### A. ผู้ใช้ในเขตเศรษฐกิจยุโรป (EEA) (GDPR)
หากคุณอยู่ในเขตเศรษฐกิจยุโรป (EEA) เราจะประมวลผลข้อมูลส่วนบุคคลเพื่อวัตถุประสงค์ดังต่อไปนี้:
1. **การให้บริการและการวิเคราะห์เกม:** เพื่อให้คุณสามารถดาวน์โหลดเกมหมากรุก วิเคราะห์เกม และแสดงสถิติภายในแอปได้  
   *ฐานทางกฎหมาย:* มาตรา 6(1)(b) ของ GDPR (การปฏิบัติตามสัญญาเพื่อจัดหาคุณสมบัติที่ร้องขอ)
2. **การรับประกันการทำงานทางเทคนิค:** การใช้การเข้าถึงอินเทอร์เน็ตเพื่อสื่อสารกับเซิร์ฟเวอร์ของ Chess.com และ Lichess.org อย่างปลอดภัยและน่าเชื่อถือ  
   *ฐานทางกฎหมาย:* มาตรา 6(1)(f) ของ GDPR (ประโยชน์โดยชอบด้วยกฎหมายในการรับประกันการทำงานและความปลอดภัยที่เหมาะสม)
3. **การจัดเก็บข้อมูลในอุปกรณ์เพื่อการใช้งานออฟไลน์:** การบันทึกไฟล์ PGN ไว้ในอุปกรณ์ของคุณ เพื่อให้คุณสามารถเข้าถึงข้อมูลได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต  
   *ฐานทางกฎหมาย:* มาตรา 6(1)(b) ของ GDPR

## 4. บริการของบุคคลที่สาม
แอปทำหน้าที่เป็นส่วนต่อประสานสำหรับผู้ใช้ (Client Interface) เมื่อคุณใช้คุณสมบัติ "นำเข้า" (Import) อุปกรณ์ของคุณจะเชื่อมต่อโดยตรงกับ:
* **Chess.com** (อยู่ภายใต้นโยบายความเป็นส่วนตัวของ Chess.com)
* **Lichess.org** (อยู่ภายใต้นโยบายความเป็นส่วนตัวของ Lichess.org)

เราไม่ได้ทำหน้าที่เป็นคนกลาง ข้อมูล Request Headers ของคุณ (รวมถึง User-Agent ของแอป) จะปรากฏแก่บริการเหล่านี้ในระหว่างการเชื่อมต่อ

## 5. การเปิดเผยข้อมูลความเป็นส่วนตัวตามภูมิภาคและสิทธิของผู้ใช้

เนื่องจากเราไม่ได้จัดเก็บข้อมูลของคุณไว้บนเซิร์ฟเวอร์ภายนอก คุณจึงเป็นผู้ควบคุมข้อมูลของคุณโดยตรงไม่ว่าคุณจะอาศัยอยู่ในพื้นที่ใดก็ตาม

### 5.1. เขตเศรษฐกิจยุโรป (EEA) และสหราชอาณาจักร (UK)
ภายใต้ GDPR และ UK GDPR คุณมีสิทธิ์ดังต่อไปนี้:
* **การเข้าถึงและการโอนย้ายข้อมูล:** ข้อมูลทั้งหมดถูกจัดเก็บไว้บนอุปกรณ์ส่วนบุคคลของคุณโดยตรง
* **การลบข้อมูล:** คุณสามารถลบข้อมูลทั้งหมดได้ตลอดเวลาโดยการล้างแคช/ข้อมูลของแอปในการตั้งค่าอุปกรณ์ของคุณ หรือโดยการถอนการติดตั้งแอป
* **สิทธิ์ในการคัดค้าน / จำกัดการประมวลผล:** คุณอาจหยุดการประมวลผลได้ตลอดเวลาโดยการเลิกใช้งานแอปหรือปิดใช้งานคุณสมบัติการนำเข้า

### 5.2. รัฐแคลิฟอร์เนีย / สหรัฐอเมริกา (CCPA / CPRA)
* **ไม่มีการขายหรือแบ่งปันข้อมูลส่วนบุคคล:** เราไม่ขายหรือแบ่งปันข้อมูลส่วนบุคคล และเราไม่ได้ขายหรือแบ่งปันข้อมูลส่วนบุคคลใดๆ ในช่วง 12 เดือนที่ผ่านมา
* **ข้อมูลส่วนบุคคลที่ละเอียดอ่อน:** เราไม่เก็บรวบรวมหรือประมวลผลข้อมูลส่วนบุคคลที่ละเอียดอ่อนที่ต้องมีการควบคุมการปฏิเสธ (Opt-out)
* **การใช้สิทธิ์:** ผู้อยู่อาศัยในรัฐแคลิฟอร์เนียสามารถใช้สิทธิ์ความเป็นส่วนตัวได้โดยการจัดการพื้นที่จัดเก็บข้อมูลในอุปกรณ์หรือติดต่อเรา เนื่องจากเราไม่ได้เก็บรักษาข้อมูลไว้บนเซิร์ฟเวอร์ การยื่นคำขอจะยืนยันว่าไม่มีข้อมูลส่วนบุคคลภายนอกอุปกรณ์ที่ถูกจัดเก็บโดยเรา

### 5.3. ประเทศบราซิล (LGPD)
ภายใต้กฎหมายคุ้มครองข้อมูลส่วนบุคคลของบราซิล (Lei Geral de Proteção de Dados - LGPD):
* **ฐานทางกฎหมาย:** การประมวลผลเพื่อการวิเคราะห์เกมและการจัดเก็บข้อมูลในอุปกรณ์ดำเนินการภายใต้มาตรา 7(V) LGPD (การปฏิบัติตามสัญญา) การเชื่อมต่อทางเทคนิคกับ API ภายนอกดำเนินการภายใต้มาตรา 7(IX) LGPD (ประโยชน์โดยชอบด้วยกฎหมาย)
* **สิทธิ์:** คุณสามารถใช้สิทธิ์เพื่อยืนยันการประมวลผล เข้าถึง หรือลบข้อมูลของคุณได้โดยตรงโดยการจัดการพื้นที่จัดเก็บข้อมูลบนอุปกรณ์ของคุณ

### 5.4. ประเทศอินเดีย (DPDP Act 2023)
ภายใต้พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคลดิจิทัล ปี 2023 (Digital Personal Data Protection Act 2023):
* **สิทธิ์ของเจ้าของข้อมูล (Data Principal Rights):** คุณมีสิทธิ์ร้องขอให้ลบข้อมูลและถอนความยินยอมในการประมวลผล
* **การดำเนินการ:** เนื่องจากข้อมูลทั้งหมดอยู่ที่อุปกรณ์ของคุณ คุณสามารถใช้สิทธิ์เหล่านี้ได้โดยตรงโดยการล้างข้อมูลแอปในอุปกรณ์หรือถอนการติดตั้งแอป

### 5.5. เขตอำนาจศาลอื่น ๆ
หากคุณอาศัยอยู่ในเขตอำนาจศาลอื่น (เช่น แคนาดา ออสเตรเลีย สวิตเซอร์แลนด์ ญี่ปุ่น หรือสิงคโปร์) คุณยังคงมีสิทธิ์อย่างเต็มที่ในการเข้าถึงและลบข้อมูลท้องถิ่นบนอุปกรณ์ของคุณโดยตรง

## 6. การโอนย้ายข้อมูลระหว่างประเทศ
เมื่อคุณใช้คุณสมบัติการนำเข้า อุปกรณ์ของคุณจะเชื่อมต่อโดยตรงกับเซิร์ฟเวอร์ของบุคคลที่สาม:
* **Chess.com:** เซิร์ฟเวอร์อาจตั้งอยู่ในสหรัฐอเมริกา การเชื่อมต่อกับ Chess.com จะทำให้อุปกรณ์ของคุณส่งคำขอเครือข่ายมาตรฐาน (รวมถึงที่อยู่ IP และชื่อผู้ใช้ที่ร้องขอ) ไปยังเซิร์ฟเวอร์ในสหรัฐอเมริกาโดยตรง
* **Lichess.org:** โครงสร้างพื้นฐานตั้งอยู่ในสหภาพยุโรป (ฝรั่งเศส/เยอรมนี)

หากคุณเข้าถึงแอปจากภายนอกสหรัฐอเมริกาหรือสหภาพยุโรป การเริ่มต้นนำเข้าจะส่งผลให้มีการส่งข้อมูลการเชื่อมต่อข้ามพรมแดนไปยังเซิร์ฟเวอร์ของบุคคลที่สามเหล่านี้โดยตรง เราไม่ได้ควบคุมการโอนย้ายข้อมูลเหล่านี้ ซึ่งอยู่ภายใต้นโยบายความเป็นส่วนตัวของบุคคลที่สามแต่ละราย

## 7. การวิเคราะห์ การจัดทำโปรไฟล์ และ SDK ของบุคคลที่สาม
* **ไม่มี SDK ติดตามผล:** แอปไม่ได้ใช้ SDK การวิเคราะห์ โฆษณา หรือการรายงานข้อผิดพลาดใดๆ (เช่น Google Analytics, Firebase หรือ AdMob)
* **ไม่มีการจัดทำโปรไฟล์หรือการตัดสินใจอัตโนมัติ:** เราไม่ได้จัดทำโปรไฟล์ ประเมิน หรือทำการตัดสินใจอัตโนมัติเกี่ยวกับคุณโดยอิงจากข้อมูลส่วนบุคคลหรือประวัติการเล่นของคุณ
* **ไม่มีระบบวัดระยะไกล (Telemetry):** ไม่มีข้อมูลเกี่ยวกับการปฏิสัมพันธ์ของคุณกับแอปถูกส่งมายังเรา

## 8. ความปลอดภัยของข้อมูล
เนื่องจากข้อมูลถูกจัดเก็บไว้ในอุปกรณ์ ความปลอดภัยของข้อมูลของคุณจึงขึ้นอยู่กับความปลอดภัยของอุปกรณ์ของคุณเอง เราขอแนะนำให้:
* ใช้รหัสผ่านล็อกเครื่องหรือการล็อกด้วยชีวภาพ (Biometric Lock)
* อัปเดตระบบปฏิบัติการของคุณให้เป็นปัจจุบันอยู่เสมอ
* หลีกเลี่ยงการใช้แอปบนอุปกรณ์ที่ถูกดัดแปลงระบบ ("Rooted" หรือ "Jailbroken")

## 9. ความเป็นส่วนตัวของเด็ก
แอปนี้ไม่ได้มุ่งเป้าไปที่เด็กที่มีอายุต่ำกว่า 16 ปี (หรืออายุขั้นต่ำตามที่กฎหมายท้องถิ่นกำหนด หากต่ำกว่า — แต่ต้องไม่ต่ำกว่า 13 ปีในทุกกรณี)

เราไม่ได้ยินยอมให้เด็กที่มีอายุต่ำกว่าเกณฑ์นี้ใช้คุณสมบัติการนำเข้าของแอปโดยเจตนา การใช้บริการของบุคคลที่สาม (Chess.com และ Lichess.org) ผ่านแอปยังคงอยู่ภายใต้ข้อจำกัดด้านอายุของบริการนั้นๆ ผู้ปกครองที่เชื่อว่าเด็กได้เข้าถึงบริการของบุคคลที่สามควรติดต่อ Chess.com หรือ Lichess.org โดยตรง

## 10. กฎหมายที่ใช้บังคับและการระงับข้อพิพาท
นโยบายความเป็นส่วนตัวนี้และข้อพิพาทใดๆ ที่เกิดขึ้นจากหรือเกี่ยวเนื่องกับนโยบายนี้ ให้บังคับและตีความตามกฎหมายของประเทศโปแลนด์ โดยไม่คำนึงถึงหลักการขัดกันแห่งกฎหมาย การดำเนินการทางกฎหมายหรือกระบวนการพิจารณาคดีใดๆ ที่เกิดขึ้นภายใต้นโยบายนี้ จะต้องนำเสนอต่อศาลที่มีเขตอำนาจในประเทศโปแลนด์เท่านั้น

## 11. สิทธิ์ในการร้องเรียน (สำหรับผู้ใช้ EEA)
หากคุณอยู่ในเขตเศรษฐกิจยุโรป (EEA) และเชื่อว่าสิทธิ์ความเป็นส่วนตัวของคุณถูกละเมิด คุณมีสิทธิ์ยื่นคำร้องเรียนต่อองค์กรคุ้มครองข้อมูลท้องถิ่นของคุณ หรือต่อองค์กรกำกับดูแลหลักของเรา:

**Prezes Urzędu Ochrony Danych Osobowych (UODO)**  
ul. Stawki 2, 00-193 Warsaw, Poland  
เว็บไซต์: [https://uodo.gov.pl](https://uodo.gov.pl)

## 12. การเปลี่ยนแปลงนโยบายความเป็นส่วนตัวนี้
เราอาจอัปเดตนโยบายความเป็นส่วนตัวนี้เป็นระยะๆ เพื่อสะท้อนถึงการเปลี่ยนแปลงในการดำเนินงานของเราหรือกฎหมายที่เกี่ยวข้อง เราจะแจ้งให้คุณทราบถึงการเปลี่ยนแปลงใดๆ โดยการโพสต์นโยบายความเป็นส่วนตัวใหม่ภายในแอปหรือบนหน้าเว็บอย่างเป็นทางการของเรา และอัปเดต "วันที่มีผลบังคับใช้" ที่ด้านบนของเอกสารนี้

หากเราทำการเปลี่ยนแปลงสาระสำคัญในวิธีที่เราประมวลผลข้อมูลของคุณ (เช่น การเปลี่ยนจากสถาปัตยกรรมแบบ Local-First) เราจะแจ้งเตือนให้ทราบอย่างชัดเจนยิ่งขึ้น เช่น การแจ้งเตือนภายในแอป ก่อนที่การเปลี่ยนแปลงจะมีผลบังคับใช้
